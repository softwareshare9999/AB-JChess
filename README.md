# AB-JChess

> A strong UCI Jieqi engine powered by NNUE, derived from Pikafish.

This repository is a **maintained fork** of [lxsgx23/AB-JChess](https://github.com/lxsgx23/AB-JChess) by [softwareshare9999](https://github.com/softwareshare9999). Playing-strength code stays with upstream; this fork adds contributor credit, GitHub Actions, and cross-platform binaries.

AB-JChess is a free, open-source UCI engine for **Jieqi** (also known as "uncovering chess" or "dark xiangqi"), a popular Chinese chess variant where most pieces begin face-down and are revealed as they move. Built upon the NNUE-based architecture of [Pikafish](https://github.com/official-pikafish/Pikafish), AB-JChess brings modern neural network evaluation to this dynamic and fast-growing variant.

## Features

- **NNUE Evaluation** — uses an efficiently updatable neural network (NNUE) for fast, accurate position assessment, following the approach pioneered by Stockfish and Pikafish.
- **UCI Protocol** — compatible with any UCI-capable GUI.
- **V8.2 NNUE Trainer** — includes a PyTorch-based training pipeline with feature encoding, distributed training support, checkpoint validation, and runtime serialization.
- **Configurable EvalFile** — you can load custom NNUE network files at runtime via the `EvalFile` UCI option.
- **Cross-platform** — GitHub Actions builds Windows, Linux (x86-64 and ARM), macOS (Apple silicon and Intel), and Android (armv8).

## Prebuilt binaries

Download a tagged [Release](https://github.com/softwareshare9999/AB-JChess/releases), or take the `AB-JChess-all` artifact from the latest [Actions](https://github.com/softwareshare9999/AB-JChess/actions) run.

Each package includes `abjchess-20260911.nnue`. Put that file next to the engine binary (the default `EvalFile` name) or set it explicitly:

```text
setoption name EvalFile value /path/to/abjchess-20260911.nnue
```

| File | Use when |
| --- | --- |
| `AB-JChess-windows-x86-64-avx2.exe` | Windows, portable (Haswell-era AVX2) |
| `AB-JChess-windows-x86-64-bmi2.exe` | Windows, Haswell or later (PEXT) |
| `AB-JChess-linux-x86-64-avx2` | Linux x86-64, portable AVX2 |
| `AB-JChess-linux-x86-64-bmi2` | Linux x86-64, Haswell or later |
| `AB-JChess-linux-armv8` | Linux aarch64 |
| `AB-JChess-macos-apple-silicon` | macOS on M1 and later |
| `AB-JChess-macos-x86-64-avx2` | macOS on Intel |
| `AB-JChess-android-armv8` | Android aarch64 |

A `vnni512` Windows/Linux build is **not** shipped. This engine's NNUE kernels use AVX2, not VNNI, so a VNNI512 binary does not search faster than BMI2.

## Usage

AB-JChess does **not** include a graphical interface. You need a UCI-compatible GUI to use it.

### Basic UCI Commands

```text
uci
isready
position fen <FEN string>
go movetime 5000
```

The FEN format is compatible with Pikafish's Jieqi branch, so positions generated by Jieqi GUIs or the Pikafish Jieqi build can be used directly.

## Building from source

From `src/`:

```text
make -j build ARCH=x86-64-avx2
make -j build ARCH=x86-64-bmi2
make -j build ARCH=apple-silicon COMP=clang
make -j build COMP=ndk ARCH=armv8
```

Run `make objclean` before switching `ARCH` or `COMP`. Download the network with:

```text
bash .github/scripts/fetch_nnue.sh .
```

## NNUE Training

The `abjchess-nnue-pytorch/` directory contains the complete training pipeline for the V8.2 NNUE network. It uses the `HalfKAv2_hm_jieqi_v8` feature set, specifically designed for Jieqi.

### Training Workflow

1. **Install dependencies** (Python 3.10+):
   ```bash
   pip install -r requirements.txt
   ```

2. **Build the native data loader** (if required):
   ```bash
   cmake -S . -B build-v8 -DCMAKE_BUILD_TYPE=RelWithDebInfo
   cmake --build build-v8 --config RelWithDebInfo
   ```

3. **Train the network**:
   ```bash
   python train_v8.py --features HalfKAv2_hm_jieqi_v8 --gpus 1
   ```

4. **Export a runtime package**:
   ```bash
   python serialize_v8.py --features HalfKAv2_hm_jieqi_v8 \
       --probability-score-to-mass <file> \
       --probability-mass-to-score <file>
   ```

The exporter produces a container using the `ABJCHESSV82` format, with score inputs in the `-2000..2000` range and mass outputs in `-950..950`.

For detailed training documentation, see `abjchess-nnue-pytorch/README.md`.
